Barbarian Codex — ฐานข้อมูลนิยาย Surviving the Game as a Barbarian (สำหรับออกแบบเกม)
=====================================================================================
วิธีเปิด: ดับเบิลคลิก index.html (เปิดด้วย Chrome / Edge) ไม่ต้องใช้อินเทอร์เน็ต ไม่ต้องติดตั้งอะไร
สลับภาษา: ปุ่ม EN/TH มุมขวาบน   ธีมมืด/สว่าง: ปุ่มพระจันทร์   ค้นหา: กด / แล้วพิมพ์ชื่อ (ไทย/อังกฤษ/เลขตอน)

โครงสร้างไฟล์
  index.html            หน้าเว็บ
  assets/app.js         โค้ดเว็บ (vanilla JS)
  assets/style.css      หน้าตา
  data/db.js            ฐานข้อมูลทั้งหมด (window.DB = {...})  ← แก้/ต่อยอดได้ เป็น JSON
  data/story/arc_XX.js  สรุปฉากภาษาไทยรายตอน แยกตาม Arc

ข้อมูลมาจากตัวบทนิยายเท่านั้น ทุกรายการมีเลขตอนอ้างอิง (Ch. N) เพื่อค้นต่อในไฟล์ Word ได้
หน้าตรวจข้อมูล: เลื่อนลงล่างสุดของเว็บ > Data check
